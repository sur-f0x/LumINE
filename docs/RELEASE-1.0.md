# LumINE 1.0

Windows 10 Mobile 1703 向け非公式 LINE クライアントの初回公開版。

- 本人確認を伴うログイン、保存済みセッションの復元、ログアウト
- 友だち・グループのトーク一覧、最新メッセージと未読件数、検索
- テキスト・写真・スタンプの送受信、動くスタンプ
- 既読、返信、送信取り消し、リアクション
- E2EE の鍵世代管理とグループ鍵の再作成
- バックグラウンド通知、通知先トークへの移動、タイル・ロック画面の件数表示
- Windows Hello と通知内容・スタンプ再生の設定
- Vyline への謝辞、依存ライブラリのライセンス表示

公開名・タグは **LumINE 1.0 / v1.0**。内部のパッケージ版 **1.0.1.0** は、動作確認済みの既存インストールからの更新互換性のため維持しています。

通信先は非公開仕様のため、LINE 側の変更により動作が変わる場合があります。メイン端末変更で失われた過去の E2EE 鍵を復元する機能はありません。端末再起動後の通知と常駐待受には OS の制約があります。
